# 屏蔽策略生效状态

列表保留启用开关，新增独立“生效状态”列：待生效、当前生效、已过期、已禁用、时间异常。禁用优先于时间状态；缺失或非法日期、结束早于开始显示时间异常。无效时间/时长使用“—”占位，避免NaN。

时间按现有后端 utils.ParTime 的 Asia/Shanghai 规则解析，兼容横线及旧点分日期。生效区间含起止秒，与后端Unix秒比较一致。页面每秒使用当前时钟重新计算，不发送额外HTTP；keep-alive页面离开停止计时，恢复立即更新，销毁清理计时器。生效状态依据浏览器当前时钟，设备时钟不准确会影响显示。

状态仅表示当前启用和时间窗口，实际屏蔽仍由后端按告警发生时间、条件、实例、渠道判断。该功能不修改屏蔽执行逻辑，也不自动修复已有异常配置。

开关保存期间禁用重复操作；业务失败或网络异常恢复原状态，并保留尚未保存的编辑表单。新增简体、英文、繁体文案。宽表仅在容器内横向滚动，手机不会撑宽整个页面。

- `src/pages/alarm/i18n.js`：三种语言文案。
