# 值班日历紧凑化

日期格从固定 168px 改为按视口高度使用 76–88px，手机为 76px。保留周一至周日七列和整月数据；默认显示首个班次的时间、人员，其余班次通过数量入口进入有滚动边界的完整详情。顶部当前接收人和匹配说明合并展示，减少纵向占用。

翻月使用“上个月 / 本月 / 下个月”文字按钮；继续按排班时区加载完整月份。未引入依赖，未修改后端和分发逻辑。

验证：33 项 Node 测试通过，包含跨年翻月、完整月份请求、多班次详情保留；lint 和生产构建通过。浏览器使用模拟数据验证 1366×768 和 390×844，手机七列无横向溢出，前后翻月、本月和班次详情均可操作。小高度视口仍允许在弹窗内滚动。
