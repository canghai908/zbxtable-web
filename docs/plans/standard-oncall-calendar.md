# 标准排班月历与列表滚动条

- 月历固定周一至周日七列、六周网格，补齐前后月日期；支持上一月、下一月、本月。
- 月视图按排班时区请求完整月份；选定时刻的接收人单独读取，避免用月初接收人冒充选定时刻。明细列表保留未来7/14/31天滚动预览。
- 桌面日期最多显示两条班次，更多班次在受限高度的日期详情中查看；手机仍为标准七列，展示班次摘要并可点击查看完整信息。
- 列表彩色条带来自强制横向滚动轨道。移除列表 scroll.x 常驻设置，改为外层 overflow-x:auto，宽屏不显示滚动条，窄屏仅必要时提供细灰色滚动条。

验证：31项前端测试覆盖周列对齐、月份长度/闰年、跨年、DST边界、整月请求和选定时刻结果独立；lint/生产构建/diff检查。实际Vue组件隔离预览1366×768与390×844，日历七列、翻月请求、日期详情及列表滚动均通过。使用模拟API，未测试物理设备。
