# 排班可视化与编辑窗口

- 默认以班次日历展示后端预览结果，按排班时区拆分日期；可切换原明细列表。
- 轮班、代班、兜底、无人接收使用不同来源标识，点击班次在所在日期内显示原因和完整带时区时间。
- 日历保留实际时间区间，覆盖跨午夜、DST 23/25 小时日、重复小时、短时代班；不在浏览器计算值班归属。
- 时区改为可搜索选择器，常用城市置前，浏览器支持时补充完整 IANA 列表，保留已有值。
- 编辑器分为基本设置、轮班成员、覆盖范围、空班兜底，宽屏两列、窄屏单列，底部操作保持可见。
- 起点输入保留原本机时间语义，同时显示所选排班时区对应的起点/交接钟点。

验证：17 项前端测试、lint、生产构建、diff 检查；实际组件隔离预览1366×768与390×844，测试时区中文搜索和班次详情展开。后端匹配/接口无需改动。
