# 全局紧凑度调整

保持现有 Ant Design Vue、主题色、14px 正文字号与 32px 默认控件高度。

1. 在共享主题层统一表单行距、卡片、表格、弹窗间距。
2. 弹窗按视口约束宽高，正文滚动，标题与底部操作保留。
3. 页面外边距与页头负边距成对调整，避免布局偏移。
4. 规则编辑器收紧内部间距；屏蔽时间表单与条件行窄屏重排。
5. 用现有 Vue/Ant Design 组件制作隔离预览，检查 1366×768、1024×600、390×844；运行 lint、条件测试及生产构建。

密度调整优先压缩空白，不全局缩放，不缩小正文字号。触屏维持可操作高度。只调整视觉和响应式布局，不改变保存、匹配与发送逻辑。
